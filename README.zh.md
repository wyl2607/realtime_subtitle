# 中文说明

仓库首页就是中文完整文档，请直接阅读 **[README.md](README.md)**。

macOS（14+ / Apple Silicon）请看 **[docs/macos.md](docs/macos.md)**，
安装只要一步：`bash scripts/macos/install.sh`（国内镜像加 `--mirror`），
并且**首次启动前要先在「屏幕与系统音频录制」里给终端授权**，否则抓不到声音。
