德语直播实时字幕 —— 使用说明
================================

这是什么
--------
在电脑上播放任何德语音视频（YouTube德语直播、Twitch、本地视频等），
自动识别德语语音并实时翻译成中文，用悬浮字幕窗显示（德语原文 + 中文翻译）。
全程本地运行（Whisper 识别 + 本地 Ollama 跑 Qwen 翻译），不联网翻译、不上传任何音频。

五个脚本
--------
启动字幕.bat      双击启动。会自动检查/拉起 Ollama 服务、检查翻译模型，
                  然后打开字幕程序。悬浮窗几秒内就会出现，识别/翻译模型
                  在后台继续加载 10-30 秒（悬浮窗上有"正在加载"提示，
                  提示消失变成"已就绪"后即可正常识别翻译）。
更新字幕.bat      一键更新到 GitHub 上的最新版（修bug/新功能后用）。
                  个人配置和字幕记录不会被覆盖；更新后重启字幕生效。
暂停继续字幕.bat  双击可以暂停识别翻译（悬浮窗还在，但不再消耗GPU做识别），
                  再双击一次就恢复。不需要重启，比停止/启动快很多。
                  ★ 更方便的方式：直接按 Ctrl+Alt+P（全局快捷键，游戏里
                  也能按，效果和这个bat一模一样）。
停止字幕.bat      关闭字幕程序（优雅退出，一般1-2秒；5秒没退完直接强杀）。
卸载字幕.bat      不想用了、或者想腾磁盘空间时用。会逐项列出各部分占多大
                  （venv／识别模型／翻译模型／Ollama 本体），一项一项问你
                  删不删，默认都是"不删"，直接回车就跳过。你的字幕存档和
                  个人配置一律保留，不会动。
                  ★ 只是想腾点空间、还要继续用：在程序目录跑
                    powershell -ExecutionPolicy Bypass -File uninstall.ps1 -CleanCache
                    它只清中断下载留下的垃圾文件，不碰能用的东西。

使用步骤
--------
1. 双击"启动字幕.bat"，看到"已启动 (PID xxx)"后黑窗口会自动关闭
   （程序在后台运行；只有启动出错时窗口才会保留，方便看报错。
   运行日志写在 {{INSTALL_DIR}}\subtitle.log，出问题时把它发给AI看）。
2. 屏幕上会出现一个黑色悬浮字幕窗：
   - 左上角有个常驻小标签显示当前【模式】（📺直播/🎬看剧/⚡性能/🎧精听，
     手动改过参数则显示"⚙️ 自定义"）。
   - 鼠标移到窗口上，顶部会出现「⠿ 实时字幕 · 拖这里移动」标题条，
     按住拖动即可挪位置；字幕正文区域按住拖也能移动。
   - 鼠标移到窗口"边缘或四角"会变成双向箭头，拖拽调整大小。
   - 窗口拉得越大，自动显示的历史句对越多；字号可用 Ctrl+滚轮调。
     位置/大小/字号/模式会自动记住，重启后保持。
   - 若完全点不到窗口：多半开了「鼠标穿透」，按 Ctrl+Alt+M 关闭即可
     （开着时右上角有 👻 提示）。
3. 播放德语音视频（默认抓 Windows"默认播放设备"的系统声音；换耳机/音箱
   时程序会自动跟着切换，约5秒内生效。若要固定某一设备，点⚙️在
   「设备名包含」填设备名的一部分，例如 FiiO 或 Speakers）。
4. 德语原文会边说边出现在字幕窗最下面一行（灰色的词是还没定稿的、可能会变，
   稍后会变白定稿——精听时以白色文字为准）。说到半句时会先出现一行
   "浅蓝色斜体"的草稿中文（先让你看个大概意思）；一句话说完后送去正式
   翻译，翻译好的德中对照会成对显示在上方，草稿自动消失。
5. 悬浮窗右上角五个按钮（鼠标移入才出现，看剧时零遮挡）：
     ➖ 最小化/恢复字幕文字（窗口还在，再点一次就能恢复看到字幕）
     📜 打开字幕历史窗口（本场全部字幕，可以往上滚动回看错过的句子）
     📺 电视全屏模式（在另一块屏/电视上全屏显示大字中文，Esc 退出，
        Ctrl+滚轮调字号，🖥 按钮换到别的屏幕）
     ⚙️ 参数调节面板（模式切换 + 识别节奏、句对条数、颜色、字体等）
     ❌ 退出程序（会弹确认框）
6. 全局快捷键（游戏里也能按；唯一例外：前台是"以管理员身份运行"的
   程序时热键无效，这是Windows的安全限制）：
     Ctrl+Alt+P  暂停/继续识别翻译
     Ctrl+Alt+L  切换源语言（德语↔英语，看英文直播也能用，不用重启）
     Ctrl+Alt+M  鼠标穿透开/关（开了以后字幕窗完全"隐形"，鼠标点击直接
                 穿过它落到下面的视频/游戏上，全屏看剧不挡操作）
     Ctrl+Alt+G  一键跳到「⚡性能」模式（识别频率减半+关草稿中文+换轻量
                 翻译模型，把显卡让给游戏；字幕会慢1-2秒但不占卡）。
                 再按一次跳回按之前所在的模式。
7. 四个模式（⚙️面板顶部，点哪个就整套套用哪套参数，左上角指示器会跟着变）：
     📺 直播 —— 新闻/直播语域，句对显示多，反应快
     🎬 看剧 —— 影视对白语域，句对条数适中
     ⚡ 性能 —— 让显卡给游戏，识别降频、换轻量翻译模型
     🎧 精听 —— 最快的识别节奏 + 偏直译的翻译，适合学德语
8. 点词查词（学德语神器）：直接用鼠标"单击"字幕里的任何德语单词，
   旁边会弹出小窗显示：原形、词性、中文释义、它在这句话里的意思。
   弹窗15秒自动消失，点一下它也会消失。拖动窗口不受影响
   （按住拖动=挪窗口，原地单击=查词）。
9. 所有字幕自动存档在 {{INSTALL_DIR}}\transcripts\
   每天一个txt文件（时间+原文+中文），可以回头搜某句话、当学习材料。

常见问题
--------
- 完全没反应/没有任何德语文字出现：先确认视频真的在出声音，且是从"默认播放设备"
  出来的（不是耳机/HDMI等其它设备）。
- 只有德语没有中文：多半是 Ollama 没运行或翻译模型没拉下来。跑一次
  "启动字幕.bat"（它会自动拉起 Ollama），或看 subtitle.log 里的提示。
- 刚启动时第一句翻译慢：翻译模型要从磁盘装进显存（开机后第一次可能要
  半分钟），这段时间悬浮窗会提示"翻译模型首次加载中"，德语照常显示。
- 字幕窗不见了：可能被最小化了，去悬浮窗残留的按钮条上点一下➖恢复；
  如果连按钮条都看不到，直接跑一次"停止字幕.bat"再"启动字幕.bat"。
- 一边打游戏一边看字幕：按 Ctrl+Alt+G 切到「⚡性能」模式。
- 不小心双击了两次"启动字幕.bat"：不会出问题，第二个会自动检测到
  已在运行并弹提示退出（单实例保护）。
- 想换成更准/更快的效果：让你的 AI 助手按仓库 CLAUDE.md 第2节改
  {{INSTALL_DIR}}\config_local.py 里的 WHISPER_MODEL 和 OLLAMA_MODEL
  （写 config_local.py 不写 config.py，以后 git 更新才不会冲突）。

技术细节和给AI的备注见仓库里的 CLAUDE.md（{{INSTALL_DIR}}\CLAUDE.md）。
