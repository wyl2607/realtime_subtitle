# v3.2.0：可选云端识别 + 多台算力节点（草稿，未发布）

> 草稿 2026-10-18。基于 v3.2.0-beta（2026-10-11）之后 feat/macos-native 的 92 个提交。发布前要按 `.governance/release-checklist-v3.2.0.md` 补完真机项，并把「测试」一节换成实际数字。

beta 里的功能都在（可选 Groq 云端识别、云端 → 节点 → 本机三档自动路由、本地额度记账、Windows 接入节点、`--client` 下发配置），下面只写 beta 之后的变化。

## 新功能

- **字幕样式可调**
  - Windows：⚙️「字幕样式」可调字号、原文/译文颜色、背景、阴影、圆角，还能切双语/仅译文/仅原文。改了马上生效，下次启动还在。
  - Mac rslite：有单独的设置窗口（⌘,），分样式 / 云端 / 识别与语言 / 节点四页。字幕窗哪里都能拖，拉边缘能改大小，位置会记住。
  - 两端颜色和字号读同一份设计令牌，风格一致。
- **字幕动效（Mac）**：新字幕淡入并上移，旧句变暗。窗口拉高就变成瀑布流，可以用滚轮回看。
- **翻译失败看得见**：没翻成的句子显示「未翻译 ⟳」，点一下重试；后台还会先自动重试一次。积压丢句会提示，不再悄悄丢掉。
- **rslite 运行模式**：默认只用本机，可选「自动」或用 `--node` 指定节点。设置页能对比各节点、测速。
- **一台节点服务多台设备**
  - 一个节点同时最多服务 2 个会话，轮流处理，互不抢占。
  - 每台设备有自己的 token，可以单独吊销。
  - `scripts/node/pair_device.sh` 给新设备生成配对码（`--rotate` / `--revoke` / `--list`）。
- **集群管理**：`python3 scripts/node/cluster.py status | update | doctor`。可以一次看全部节点的状态、一次全部更新（正在用的节点默认跳过），也能逐台体检 Ollama、Tailscale、磁盘和代码版本。

## 改进

- **节点出字更快**
  - 识别不再要词级时间戳：M4 上每段 1.78s → 0.98s。直播实测句末到原文 2.94 → 2.11s，到译文 3.36 → 2.20s，WER 没变。
  - 分段静音阈值按段长自适应：连续讲话时出字更快。真实直播 p50 4.3 → 2.84s，WER 5.30% → 6.31%。
  - 节点单段上限 15s → 8s：网页视频没有停顿时，不会再一卡 15 秒才出字。
- **节点翻译更准**
  - 会话开始时就预热翻译模型，冷启动首句从 9–15s 降到 0.7s。
  - 翻译时带上上一句作为上下文。
  - 先把德语时间写法规范化。原文里的数字如果没出现在译文里，就自动重试一次（修了「2,1 %」被译成「1.2%」的问题）。
- **节点更稳**
  - 网关会看护本机 Ollama：连续两次探测失败就自动拉起，Windows 实测约 110 秒恢复。
  - Mac 节点装了 Tailscale 保活（每 5 分钟检查一次）。
  - 路由会避开内存吃紧、正在大量换页的节点。
- **中文统一简体**：目标语言是中文时，节点和桌面 Ollama 的输出都转成简体。
- **语言切换更干净**：切换前发出、切换后才回来的远端/云端结果会被丢掉，不会再用新语言显示一次。
- **云端与节点切换更省心**
  - 云端被限流（429）进入冷却时，状态行会带上「· 云端限流冷却」，不用猜为什么没走云端。
  - 节点冷启动时会显示「<节点> 正在加载模型…」，最多等 60 秒，不再过早判失败。
  - key 被判无效之后，晚到的限流响应不会把路由带回云端。
- **Windows 远端替换全覆盖**：节点句替换本机句时，历史窗、电视窗、影院条也一起替换，不再重复显示。

## 修复

- rslite 偶发崩溃（SIGSEGV，栈顶是 `isMainExecutor`）：根因是 AppKit 吞掉了一次 ObjC 异常，留下损坏的执行器状态。现在根因已修，以后再出现被吞掉的异常会当场崩溃，方便定位。修复后连续运行 16 小时以上没有再崩。
- 浅色系统外观下，rslite 字幕底板变浅，白字和黄字看不清。
- 节点选择时识别模型名没有归一，质量分全部落到默认值。
- `cluster.py` 在中文 Windows 上遇到 GBK 报错会崩。
- rslite 的 key、云端开关、额度账本、样式、设置现在和节点配置一样认 `RSLITE_CONFIG_DIR`。以前设了这个变量也照样写进 `~/.config/rslite`。

## 隐私与安全

- 和 beta 一样：音频离开本机只有两条路，都要你主动配置——自己的 Tailscale 节点，或 Groq。
- 每设备 token 用常量时间比较，可以单独吊销；旧的单 token 仍能用。
- rslite 连节点前会校验地址属于 Tailscale 网段，并钉住 IP（`/v1/info`、测速、`/v2/session` 都是）。

## 已知问题

- 自适应分段换来了更快的出字，代价是直播 WER 约 +1pp（5.30% → 6.31%）。
- macOS 15 的节点用不了系统翻译，会退回 Ollama。
- 节点机重启后要有人登录，节点才会起来（LaunchAgent 依赖登录会话）。
- 分发形式仍是源码。仓库里已经有 rslite .app 打包脚本和 Windows 引导安装器，但它们属于 v3.3，本版不提供下载。
