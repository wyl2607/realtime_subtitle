# v3.3.0：Windows 可借系统实时字幕识别；字幕上屏更稳，云端额度恢复后自动回云端

## 需要你动手

- **最低 Python 版本从 3.10 提到 3.11（支持 3.11–3.13）**。上游的 torch 2.15 和 yt-dlp 2026.10.26 都不再提供 Python 3.10 版本，3.10 用户更新依赖会装不上。还在 3.10 的 Windows 用户请先装 Python 3.11 或更高版本，再重跑一次 `scripts\windows\install.ps1`。Mac 用户按 `scripts/macos/install.sh` 重装即可。

## 新功能

**Windows**

- **免显卡识别：借系统实时字幕**
  - 新增 `ASR_SOURCE = "livecaptions"`。打开后程序读取 Windows 11 实时字幕的文字，不加载 Whisper、不采集音频，适合没有独立显卡的机器。
  - 系统字幕进程退出会自动重连；非 Windows、缺少 `uiautomation` 或找不到系统实时字幕时给出提示并回退 Whisper。
  - `uiautomation` 是可选依赖，不装不影响原来的识别方式。
- **每次运行另存双语 SRT + CSV**：默认在字幕存档目录下按每次运行生成一份 SRT 和一份 CSV，时间轴保证单调不重叠。受 `SAVE_TRANSCRIPT` 总开关约束，保留期清理也会一并覆盖这些文件。
- **历史回看更好用**：主窗、历史窗、电视窗、影院条改为订阅同一份字幕历史。历史窗新增时间和来源标记、搜索、复制全文、导出 SRT，语言切换处有分界线。

**节点**

- **可选 SenseVoice 识别**：设置 `ASR_ENGINE = "sensevoice"` 后，节点 worker 用 SenseVoice-Small 识别中、英、日、韩、粤。遇到不支持的语言（含德语）或缺 `funasr` 时自动回退 Whisper。本机流式识别仍用 Whisper。

**Mac rslite**

- **字幕出现更自然**：瀑布流补上最短停留时间，新句不会刚出现就被挤走；译文第一次到达时淡入。
- **可以打包成 .app**：新增打包脚本、打包后自检和 CI 打包。最低系统为 macOS 27；未公证的包首次打开要按 Gatekeeper 提示选「仍要打开」，文档和权限弹窗说明已补齐。
- **当日字幕存档 + 「今天的字幕」窗口**：定稿句对按天写进 `transcripts/YYYY-MM-DD.txt`（格式与 iOS 相同）；菜单栏「今天的字幕…」打开当天历史，支持搜索、复制全部、在访达中显示，跨过午夜自动切到新一天。存档读不出来时不会覆盖原文件，写盘失败会在下一次更新或退出时重试。

**iOS（实验性，仅源码）**

- 主界面改为「字幕 / 设置」两页；设置分「字幕样式 / 识别与语言 / 算力节点 / 诊断」，配对链接打开后直接跳到算力节点页。
- 「今天的字幕」支持卡片样式、搜索、复制和导出。
- 本机档的草稿实时上屏，定稿按句切开。

## 改进

**Windows**

- **新句上屏不闪**：已经显示的句子只在新句到来、窗口变化或最短停留时间到期时挤出，live 文字变高不会再挤掉旧句。新句对按设定时长淡入。
- **草稿转正式句对原位替换**：草稿晋升为正式句对时，同一帧从 live 行去掉原文，不再重复显示，也不会重新淡入一次。

**Mac rslite**

- 水位文字、翻译中占位和状态词都改用统一设计令牌，状态行和设置页说法一致。
- 不在节点列表里时，状态提示改为明确取节点令牌，不再各写一份。

**iOS**

- 本机引擎的可变状态收进一把锁，修掉线程竞态。
- 额度账本的状态词、字幕样式改用统一模型，为后续维护减少分叉。

**云端与节点（Windows / Mac rslite / iOS）**

- **额度恢复后自动回云端**：三端额度账本会读 Groq 的 `x-ratelimit-reset-requests`，记住服务端额度恢复时刻；过了恢复点就自动结束冷却、重新走云端。
- **翻日额度更可信**：新增可信 RPD 翻日信任门，服务端水位和本地记录对不上时以更保守的一侧为准，避免刚翻日就把额度用光。
- **三端行为一致**：同一份路由输入在 Python、Swift（rslite）和 iOS 上得到相同结果，异常一律按 fail-closed 处理。

## 修复

**Windows**

- **德语断句更准**：德语缩写和句中的省略号不再被误当成句末；实时路径里「……」「z. B.」这类否决条件真正生效。
- **中文标点更稳**：连续的「……」「？！」「？？」整体算一个句子边界，不再切成多段。
- **系统实时字幕真机问题**：改用最小化而不是隐藏窗口；连上时跳过窗口里残留的旧文字；`tasklist` 输出按 OEM 编码读取；丢掉只有标点、没有字母数字的残留句。系统压着的旧尾巴也不再整句吞掉。

**Mac rslite / iOS**

- 修掉额度账本的多处 fail-open：异常数字、越界剩余额度、换 key 后迟到的旧响应、墙钟回拨、重启后的冷却状态，都不会再让额度记错或提前解除冷却。
- rslite 的「重试中」文案改为引用统一的翻译中令牌，不再有写死的副本。

**其他**

- 修掉 iOS 在 Xcode 26.6 下的闭包循环引用问题，以及 Swift 6.3 下同名局部变量遮蔽导致的卡死。
- 跨端一致性检查在 Windows 上统一用 `/` 输出路径，断言不再因分隔符失败。

## 测试与工程

- 最低 Python 版本改为 3.11–3.13，`deps-resolve`、安装脚本、三语 README 和 ruff 目标版本同步更新。
- 依赖升级：torch 2.15、yt-dlp 2026.10.26、PyQt6 6.12、ctranslate2 4.8.4；ruff 钉到 0.17.3，CI 的 `actions/cache`、`actions/setup-python` 一并升级。
- 一致性检查现在覆盖四端生成物（rslite / iOS Swift、Python、Android Kotlin）；新增状态文案「无写死副本」检查并接入 CI。
- rslite 自检改为 fail-closed：保留退出码并精确比对三行输出，减少 CI 误放行。
- 其余 CI、测试和文档提交合并处理，包括 Windows 上 token 目录 mtime 的偶发失败和字幕存档用例跳过 `sessions/` 目录。
