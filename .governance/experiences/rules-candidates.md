## 2026-10-10 — sprints-001-remote-offload

### RC-001 — 验收脚本必须失败即非零，且判据不能只看“有输出”
- 触发条件：新增或修改 `scripts/bench/**`、smoke、acceptance probe，尤其是会生成 `ok` 字段、评分表或最终验收结论的脚本。
- 反例引用：CR-014 `node_lifecycle_probe` 的 `ok:false` 仍 exit 0；CR-014 `hybrid_score` 依赖不存在的 `source` 字段导致 C/混合 WER 被算成 1.0；CR-014 `multi_node_probe` R2 F8 混用墙钟 t 与音频轴 t0；`docs/node-acceptance.md` 第 4 条记录评分器修复后才暴露 TK-010 重复字幕。
- 候选规则：验收脚本提交前必须有至少一个“修复前红、修复后绿”的负例，且脚本自身失败必须返回非零；评分器字段必须来自真实事件样本或 fixture，不得凭预期字段名编写。
- 建议沉淀位置：测试守卫 + check-fast。

### RC-002 — 远程/launchd 行为必须用空环境或真实 launchd 等价环境复现
- 触发条件：代码依赖 `PATH`、Tailscale CLI、LaunchAgent、`ps/pgrep`、`launchctl`、shell locale、或远程安装脚本。
- 反例引用：CR-007 D2 与 HANDOFF §12：App Store 版 Tailscale 在 launchd 无 `SHLVL` 时进 GUI 模式且 rc=0；CR-005 C1：真实 mini2 v1 命令行含 `python -u -m ...`，合成评审没覆盖；CR-010：macOS bash 3.2 UTF-8 下 `$var）` 吞多字节首字节。
- 候选规则：此类改动必须包含一个“真实环境等价”复现点：`env -i` 最小环境、macOS `/bin/bash` 3.2、真实 `ps -o command=` 样本、或真机 launchd/UDS/TCP 验证；只在交互 shell 中通过不算验收。
- 建议沉淀位置：SOP + CLAUDE.md 避坑条目 + check-fast。

### RC-003 — 用户配置与真实 runtime state 必须隔离，不能靠 `$HOME` 假隔离
- 触发条件：任何 smoke/bench/test 会读写 `~/.config/rslite`、`~/Library/Application Support`、LaunchAgent、token、nodes.json、或用户真实运行态。
- 反例引用：CR-009 开头记录 TK-005 冒烟覆盖真实 `~/.config/rslite/nodes.json`，且 macOS `expandingTildeInPath`/`NSHomeDirectory` 不认 `$HOME`；HANDOFF §12 16:55 同一事件；`docs/node-acceptance.md` 第 1 条仍把真机 `nodes.json` 作为验收对象。
- 候选规则：Mac app/CLI 的 smoke 必须先提供产品级配置目录 override（如 `RSLITE_CONFIG_DIR`）并断言真实配置 md5 前后不变；仅改 `$HOME` 不算隔离。
- 建议沉淀位置：测试守卫 + CLAUDE.md 避坑条目。

### RC-004 — 安装/回滚脚本必须覆盖真实旧服务命令行、并发测试隔离、失败后恢复
- 触发条件：改动 installer、rollback、旧服务停止/恢复、`pgrep`/`ps` 匹配、LaunchAgent bootstrap/kickstart。
- 反例引用：CR-005 F1 首装失败会留下指向不存在 venv 的 plist 且 v1 已停；CR-005 R2-S1 回滚重放 `ps` 命令行形成 `sh -c` 注入面；CR-005 C1 漏匹配 `python -u -m ...`；CR-005 C2 两份并发测试会互杀伪装 v1，真实 mini2 v1 也有被杀风险。
- 候选规则：installer 测试必须包含真实旧服务命令行 fixture、注入型 argv 反例、并发双跑隔离、无 `.prev` 与有 `.prev` 两种回滚；`pgrep` 全局匹配必须在测试中被桩隔离。
- 建议沉淀位置：测试守卫 + SOP。

### RC-005 — 安全/协议状态机至少三轮评审，且每轮要换关注点
- 触发条件：鉴权、token、队列上限、worker/gateway 生命周期、NodeRouter/NodeClient 状态机、并发迁移、断线回退。
- 反例引用：CR-003 Round 1–4 连续发现 F1/F2/S-F1/R2-D1/R3-D1；CR-009 Round 1–5 先后发现 F1–F5、R3-1/R3-2、R4-1/R4-2/R4-3；CR-012 R1/R2 发现 UDS 握手、安全和 selftest 影子路径缺口。
- 候选规则：状态机/安全面默认至少三轮：初审功能+安全、复审真实联调/压力、终审竞态与回归；Round 3 后仍有 high/blocker 时触发熔断或用户显式降 scope。
- 建议沉淀位置：SOP。

### RC-006 — 第三方/弱 lane 的“通过”只能作为草稿，Coordinator 必须复跑硬证据
- 触发条件：使用 agy Gemini、OpenRouter 免费模型、opencode big-pickle、grok 等外部 lane 产出实现、评审或验收结论。
- 反例引用：CR-009 执行接力中 Gemini pro 自称冒烟 4/4，Coordinator 复跑证伪为 `switch_failed` 回本机；CR-013 R2 big-pickle 引用不存在的 UDS.swift/Session.swift/RemotePipeline.swift，整份驳回；CR-014 R3 agy 删除 fake worker hello 清零与 token 泄漏检查；`feedback_lane-model-fitness.md` 记录相同模型适配坑。
- 候选规则：弱 lane 产物回收时必须先核对 diff scope、文件/行号存在、关键测试由 Coordinator 或强 lane 复跑；弱 lane 不得作为唯一验收/终审来源。
- 建议沉淀位置：SOP + CLAUDE.md 避坑条目。

### RC-007 — 跑 rslite 的验收/冒烟全局串行
- 触发条件：任何脚本会启动 `rslite`、占用单实例 flock、连接 UDS/TCP node、或采集功耗。
- 反例引用：HANDOFF §13 明确“跑 rslite 的东西全局串行”；`docs/node-acceptance.md` 第 6 条记录 10-10 10:42 功耗轮次因协调者同时跑第 2 条探针而作废；`tk007_crit6_power.md` 作废轮次同样记录空闲组被 rslite 干扰。
- 候选规则：含 rslite 的验收任务进入独占队列；功耗、multi_node、hybrid_e2e、UDS 冒烟不得并行，脚本/任务卡需写明独占。
- 建议沉淀位置：SOP + check-fast。

### RC-008 — 文档/协议清理必须先做残留引用扫描，并区分“有意保留 v1 兼容”
- 触发条件：删除旧协议、旧服务目录、迁移 protocol docs、更新 CLAUDE.md 运行说明。
- 反例引用：CR-008 F1/F2 发现 `protocol-v2.md` 漏 1009 与 `internal_error` 语义不准；CR-008 F3 指出 v1 残留但被分诊为切分支时序/其他 TK；TASKS TK-006 notes 要求 `worker_crashed`、status code、TAILSCALE_BE_CLI 等同步落文。
- 候选规则：文档清理必须跑一次残留引用扫描并把命中分类为“已删除旧路径 / 有意兼容 / 其他 TK 已负责”，避免误删或误报。
- 建议沉淀位置：check-fast + SOP。

### RC-009 — 事件流/时间轴类逻辑必须有轴一致性测试
- 触发条件：处理音频样本时钟、墙钟、`t0/t1`、丢帧补零、P5 替换、multi-node 迁移、hybrid scoring。
- 反例引用：CR-001 F1/N1：AudioFanout 丢块/跳变会让 t0/t1 前移；CR-003 F2：gateway 丢帧导致 worker 样本时钟错开；CR-009 R3-2：AudioFanout 丢帧使节点 a0 永久偏前；CR-014 multi_node R2 F8：墙钟 t 与音频轴 t0 混用。
- 候选规则：时间轴改动必须同时覆盖样本轴、音频轴、墙钟轴，不同轴转换需显式命名；测试 fixture 要包含丢帧、迁移、断线、节点拆句。
- 建议沉淀位置：测试守卫 + check-fast。

### RC-010 — Sprint 治理时间戳必须实测，不允许估算
- 触发条件：写 `CURSOR.md`、`metrics/phase-trace.jsonl`、handoff、review close time、或跨时区接手记录。
- 反例引用：CURSOR 记录“15:20 之后几条记录时刻估算、偏晚约 1.5–2h”；`phase-trace.jsonl` 存在 2026-10-09T18:50+02 后插入 2026-10-09T17:10+02 的真实时间倒跳；`evidence/tk007_crit6_power.md` 对 10-09 23:28、10-10 10:42、10-10 10:5x 三轮作废测量按真实时间留档；HANDOFF §12 明确“写前跑一次 `date +%H:%M`”。

- 建议沉淀位置：SOP + check-fast。
