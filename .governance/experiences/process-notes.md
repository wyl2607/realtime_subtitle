### Context switching bottlenecks

- Timezone/context transitions were material. The log switches from CST cloud time to CEST local time, and the explicit correction around 17:10 CEST shows estimated governance timestamps can corrupt duration analysis unless normalized and checked.
- Approval-gated hardware operations were the largest non-review bottleneck: mini2 install approval, remote rollback drill, gateway shutdown fallback, and sudo power measurement required user or machine-state coordination. These are visible in the `acceptance` total and in `tk007_crit1_crit3_user_run.log`.
- Lane capability mismatches created extra coordination load. Codex quota interruptions affected TK-001 and TK-005; agy/Gemini overclaimed or overstepped in CR-009/CR-014; big-pickle fabricated CR-013 references. The fitness table update was necessary process state, not just commentary.
- True macOS/runtime verification could not be replaced by cloud tests. CR-007 needed launchd/Tailscale behavior; CR-010 needed bash 3.2 UTF-8 behavior; CR-005 needed macOS `ps/pgrep`; CR-009 needed real config isolation.

### Parallel batch performance

- The early parallel batch TK-001 + TK-004 was effective after codex quota fallback: both reached review quickly, but TK-004 still correctly blocked on Mac build before merge.
- Security/remote tasks benefited from serialization. TK-002, TK-003, TK-002b, TK-005b each exposed lifecycle/security issues that would have been expensive if merged without staged review.
- The 15:20 CEST multi-lane acceleration improved throughput for disjoint write scopes (TK-002b, TK-005, TK-006), but only because Coordinator enforced merge order and repeated local verification.
- rslite-running tasks did not compose in parallel. `docs/node-acceptance.md` and `tk007_crit6_power.md` show at least one power run was invalidated by concurrent rslite work; future acceptance batches need an explicit single-lane rslite lock.

### Review loop signal

- Multi-round review paid for itself. Examples: CR-003 found queue memory, ready ordering, stale worker events; CR-005 found rollback no-service, command injection, real mini2 `-u` mismatch, and test mutual killing; CR-009 found pause/resume, migration fallback, silent disconnect, clock drift, gap padding, and fsync/fchmod issues.
- However, weak reviewer lanes need evidence gates. CR-013 big-pickle fabricated file names; CR-014 agy removed safety checks; CR-009 Gemini reset history and overclaimed smoke success. The process worked when Coordinator treated these as inputs to verify, not as final authority.
