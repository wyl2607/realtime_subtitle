# Spec 006 — 设计系统与产品化路线

状态：requirement（2026-10-11 用户确认方向）

## 用户决定（2026-10-11）
- 目标：做成真正的软件，长期可维护，**以后可能收费上架**。
- 先做：**设计规范 + 体验打磨**；工程化在后台并行。
- Windows：继续打磨 PyQt，保留以后迁到 Windows 原生（WinUI）的可能。
- Mac：原生 Swift（rslite）是长期主线。

## 原则
1. **一份规范，两端实现。** 视觉参数的唯一真相源是 `design/tokens.json`；Swift 与 Python 都从它读（构建期生成常量或运行期加载），不各写一份字面量。以后换 Windows 原生也只是第三个消费者。
2. **字幕优先。** 一切装饰让位于可读性：对比度、稳定（不跳行、不闪）、留够阅读时间。
3. **安静。** 平时只有字幕；控件悬停才出现；状态用一个词说清楚（本机 / 混合·节点 / 云端·Groq），出错才用颜色。
4. **不丢句子。** 每一句都有可见的结局：译文、或「未翻译 ⟳」。
5. **业务逻辑不进 UI 层。** 路由、翻译、历史存储都在 UI 之外，换 UI 框架不动它们。

## 设计令牌（design/tokens.json）
- 颜色：字幕原文 / 译文 / 草稿 / 次要文字；背景；状态色（正常、提醒、错误）；预设调色板（文字 5 + 背景 5，两端菜单与设置页共用）。
- 字号阶梯：字幕默认 28，范围 16–72；原文 = 译文 × 0.86；状态行 13；设置页正文 13。
- 间距：4 的倍数（4/8/12/16/24）；字幕窗内边距 18×22；句对间距 8。
- 圆角：0 / 8 / 16（直角 / 小 / 卡片）；横条为 0。
- 动效：新句淡入 150ms ease-out；旧句上移 180ms；窗口高度变化 200ms；尊重系统「减少动态效果」= 全部 0。
- 阅读时间：句子至少停留 3.0s 才允许被顶走。
- 文案：状态词表、按钮文案、错误提示的统一措辞（中文为主，留 i18n 键）。

## 商业化前置（上架前必须解决，不在当前阶段做）
- **PyQt6 是 GPL**：闭源收费分发需买 Riverbank 商业许可，或迁到 PySide6（LGPL，API 几乎一致）。建议迁 PySide6。
- 模型与依赖许可证清单（Whisper MIT、Qwen 许可证、yt-dlp 等）。
- Mac 签名/公证需正规 Apple 开发者账号（现有账号不能用，见 memory project_apple-developer-account-plan）。
- 隐私政策（云端 Groq 路径）、自动更新、崩溃报告（须可关闭、不含字幕正文）。
- 品牌：正式产品名与图标。
