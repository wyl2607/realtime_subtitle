# v3.2.0-beta：可选云端识别 + Windows 接入算力节点（预发布）

> **这是预发布版**，在 `feat/macos-native` 分支上打的 tag，不进 master。正式版 v3.2.0 要等真机验收：1 小时额度长测、6 种故障场景、Windows 真机。想要稳定版请继续用 v3.1.0。

## 新功能

- **可选云端识别（Groq Whisper）**：填了 Groq key 才会上传音频，默认仍是完全本地。
  - Mac rslite：用 `rslite --set-groq-key` 从标准输入写入 key，`--clear-groq-key` 清除，`--cloud on|off` 开关。
  - Windows：⚙️ 面板「云端识别」里填 key（不回显，可清除），并有开关。
  - 不读任何环境变量里的 key。
- **三档自动路由**：云端 → 自己的算力节点 → 本机。
  - 连续失败、限流（429）、额度用到 90% 时自动降档；恢复后在静音点切回。
  - key 无效时停用云端，改了 key 才会重试。
  - 关掉开关会立刻取消正在上传的请求，回来的结果直接丢弃。
- **本地额度记账**：按免费档（每分钟 20 次、每小时 7200 秒音频、每天 2000 次 / 28800 秒，每次最少按 10 秒计）在本机记账，并用 Groq 返回的每日剩余请求数校正。
- **Windows 客户端接入算力节点**：⚙️ 面板「使用算力节点」开关。
  - 本机先出字，节点结果随后按时间对齐替换。
  - 同一台机器既是节点又是客户端时，自动跳过自己。
- **一条命令下发节点配置**：`install_node.sh` / `install_node_windows.sh` 新增 `--client <Windows 客户端 ssh 别名>`。token 只经标准输入传，不进命令行。
- **状态行显示当前来源**：「云端·Groq」/「混合·节点名」/「本机」。

## 隐私与安全

- 音频离开本机只有两条路，都要你主动配置：你自己的节点（Tailscale 内网），或 Groq（第三方）。
  - 经过网络代理时，代理能看到上传的原始音频片段。
  - Groq 默认不保留识别请求；排查故障或滥用时可能临时保存最多 30 天，可在 Groq 控制台开启 Zero Data Retention。详见 README。
- 节点连接不走系统代理，并钉住已校验的 Tailscale IP；云端请求不跟随重定向，认证头不会被 `~/.netrc` 覆盖。
- key 文件权限：Mac 是 0600；Windows 先用 icacls 收紧临时文件，再改名为正式文件。

## 已知问题（beta）

- **全部未经真机端到端验证**：暂停/恢复后的重订阅、替换瞬间译文是否闪空、降级时菜单栏是否闪烁、Windows 下 icacls 和 PushClient 的实际 ACL，都要等明天的真机验收。
- 切换语言之前发出、切换之后才返回的远端句，可能会以新语言显示一次。
- 远端句替换本机句只作用于悬浮窗；历史弹窗、电视窗、影院条仍保留最初的本机句。
- 云端分段阈值（20ms 帧、RMS 0.005、静音 ≥0.6s 收段、15s 强切）还没有真机数据。
- 分发形式仍是源码；rslite .app 和 Windows 引导安装器计划在 v3.3。
